Der Wert aus \cref{fig:d} weicht um $\qty{0.4}{\percent}$ von einem Wert
ab, der nirgends steht \cite{zinth_optik_2018}. Mögliche Gründe:
\begin{itemize}
  \item ein erster Grund,
  \item ein zweiter Grund mit Unterpunkten,
    \begin{itemize}
      \item ein Unterpunkt,
      \item noch ein Unterpunkt,
    \end{itemize}
  \item ein Grund, der auf \cref{fig:bc} verweist.
\end{itemize}

Das Feynmansche Pfadintegral passt zwar nicht zu \cref{eq:lindblad},
steht aber trotzdem hier:
\begin{equation}
  \langle x_{b}, t_{b} \vert x_{a}, t_{a} \rangle
  = \int \mathcal{D}[x(t)]\,
    \exp\biggl( \frac{i}{\hbar} \int_{t_{a}}^{t_{b}}
    \Bigl[ \frac{m}{2}\dot x^{2} - V(x) \Bigr] \mathrm{d}t \biggr) .
  \label{eq:pfadintegral}
\end{equation}
